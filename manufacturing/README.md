## シリアル番号

裏面右下の10×2mmの白ベタは、製造時に番号を入れる位置です。

- PCB上のマークで `2D Barcode (Serial Number)` を選択。
- `Number only` と `Specify Position` を選択。
- 開始番号 `0001`、`Unique Number` は `Remove`、接頭辞は空欄。
- 製造ファイルの事前確認を有効にし、番号が裏面右下に入ることを確認。

製造上の理由で番号に欠番が生じることがあります。追加注文では開始番号を確認してください。番号サービスの設定を省略すると、白い指定領域がそのまま印刷される可能性があります。[JLCPCBの番号印刷説明](https://jlcpcb.com/help/article/how-to-mark-on-pcb)

## 変更点と検査

Rev Mではジャンパーの1–2間を0.8mm、接続銅箔幅を0.2mmに変更しています。2–3間は0.3mmです。外形の直角部は半径0.5mmで丸めています。

裏面にR1/R2、D3/D4の極性、no drink, no hackを印刷します。
